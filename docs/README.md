# Documentation

This documentation follows the [Diátaxis](https://diataxis.fr) framework. It is split into four kinds of content, each answering a different question:

| | When you want to… | Go to |
|---|---|---|
| **Tutorial** | Learn what the project is by doing | [tutorials/](tutorials/) |
| **How-to** | Accomplish a specific task | [how-to/](how-to/) |
| **Reference** | Look up a precise fact | [reference/](reference/) |
| **Explanation** | Understand the *why* behind decisions | [explanation/](explanation/) |

These first docs are written for **external readers** — journalists, researchers, and curious visitors who want to understand what the Linguist Corpus Analyzer studies and how to read its findings. Documentation aimed at people who want to run or modify the code will be added once the project is hosted on GitHub Pages.

## Start here

- New visitor? → [Take a guided tour of the dashboard](tutorials/getting-started.md)
- Need to look up a term, status, or definition? → [Reference](reference/data-and-terms.md)
- Curious why this project exists? → [Methodology and rationale](explanation/methodology.md)
- Who built this? → [About the project (CHOICE)](explanation/about.md)
